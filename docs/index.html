What is this?

Tonkatsu Collections is the official, community-curated catalogue of pre-built collections for Tonkatsu Box — the free, open-source media collection manager for Windows and Android. Each collection is a small .xcoll or .xcollx file you can import into the app in seconds.

🎮 Complete libraries

Full catalogues of officially released games per platform — Atari 2600 through PSP. Sourced from IGDB, refreshed regularly.

🏆 Top 50 picks

Highest-rated, must-play 50 games per platform — handy when you don't want the whole catalogue.

🌟 Console exclusives

4 700+ games that released only on one platform, built by cross-referencing Wikipedia categories with IGDB and verified by region (NES/Famicom, SNES/Super Famicom, TG-16/PC Engine etc.).

🎬 Movies, TV & anime

Curated film, series and animation lists powered by TMDB metadata.

How to import

  1. Install Tonkatsu Box v0.25+.
  2. In the app, open Settings → Import → Browse Online Collections, pick one, hit Download — done.
  3. Or download any file from the catalogue below and use Import → Import Collection manually.
