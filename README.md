# Tonkatsu Collections

Ready-made collections for [Tonkatsu Box](https://github.com/hacan359/tonkatsu_box) — free, open-source media collection manager.

Download a `.xcollx` file (full, with images) or `.xcoll` file (lightweight, no images), import it into the app, and get a complete collection with posters, descriptions, and ratings. Full collections work offline immediately — no internet needed after import.

## Formats

- **`.xcollx` (Full)** — includes embedded cover images (base64). Works fully offline after import. Larger file size.
- **`.xcoll` (Light)** — metadata only, no embedded images. App downloads covers on first open. Much smaller file size (~50-100 KB each).

## How to Import

1. Download a `.xcollx` or `.xcoll` file (click links above)
2. Open **Tonkatsu Box**
3. Go to **Collections** tab -> **Import** (menu)
4. Select the downloaded file
5. Done — collection is ready with all data
