# Tonkatsu Collections — Game, Movie & Anime Libraries

Pre-built collections for [**Tonkatsu Box**](https://github.com/hacan359/tonkatsu_box) — free, open-source media collection manager for Windows & Android.

**45** collections | **26,553** games across **32** platforms | **199** movies, shows & anime

---

## How to Use

### In Tonkatsu Box (recommended)

1. Open Tonkatsu Box
2. Go to **Settings > Import > Browse Online Collections**
3. Pick a collection and download

### Manual Import

1. Download any `.xcoll` file from below
2. In Tonkatsu Box: **Import > Import Collection**
3. Select the file — done!

## Repository Structure

```
tonkatsu-collections/
├── platforms/           # Game collections by platform
│   ├── nes/
│   │   ├── _platform.json    # Platform metadata
│   │   ├── complete.xcoll     # Full game library
│   │   └── top.xcoll          # Top 50 games
│   └── ...
├── media/               # Movies, TV Shows, Anime
│   ├── movies/
│   ├── tv-shows/
│   └── anime/
├── curated/             # Cross-platform curated lists
├── scripts/             # Automation (build index, validate)
├── index.json           # Auto-generated collection index
└── .github/workflows/   # CI: auto-build index, validate PRs
```

## File Format (.xcoll)

Light JSON format with external IDs (IGDB for games, TMDB for movies/shows).
Tonkatsu Box resolves metadata (covers, descriptions, ratings) on import.

```json
{
  "version": 2,
  "format": "light",
  "meta": {
    "name": "Best SNES RPGs",
    "description": "Must-play RPGs for Super Nintendo",
    "author": "hacan359",
    "category": "curated"
  },
  "items": [
    { "externalId": 1234, "platformId": 19 },
    { "externalId": 5678, "platformId": 19 }
  ]
}
```
